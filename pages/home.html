The content below is based directly on the project architecture and feature set documented in the repository README.

Live Detection

Runs real-time object detection in the browser, tracks hazards with IoU, and applies anti-spam cooldowns before saving.

  • On-device inference via TensorFlow.js
  • Worker-based architecture for fluid UI
  • Auto-save after stable consecutive hits

Smart Reporting

Creates structured hazard reports from live camera or uploaded images with GPS extraction, address lookup, and image upload.

  • Camera and gallery capture flow
  • EXIF metadata parsing and location fallback
  • Cloudinary storage with cleanup safeguards

Map + Dashboard

Visualizes reports with Mapbox GL JS, custom markers, popups, filters, report tables, and operational status workflows.

  • Interactive map with fly-to navigation
  • Filtering by status, type, date, and reporter
  • Report table with image previews and actions

Secure PWA Platform

Brings authentication, role-aware data access, installability, caching, and mobile-first performance into one secure delivery layer.

  • Firebase Auth with email and Google sign-in
  • Firestore rules for protected data access
  • Installable standalone app experience
Detection to decision

Built to keep the interface responsive while the AI keeps working in the background.

The main thread stays focused on the user experience while a dedicated worker handles model loading, inference, and result delivery.

Main thread

UI, camera rendering, map updates, and overlays

Keeps the app interactive while detections, markers, and report state stay in sync.

Worker thread

TensorFlow.js inference, parsing, and hazard geometry

Runs detection logic off the main thread to preserve fluid mobile performance.
